> ⚠️ **Migration / Port Notice**
>
> This repository is a **ported and migrated version** of  
> **LesRaisins Tactical Equipements**, adapted for **NeoForge 1.21.1**.
>
> - Original repository: https://github.com/LesRaisins-Studios/LesRaisins-Tactical-Equipements
> - Original authors: xjqsh, LeComte
> - Migration & maintenance: Nahiyus512
>
> This fork focuses on **porting the project to NeoForge 1.21.1**,
> including dependency updates, mapping changes, and compatibility fixes.
>  
> The migration process partially utilized **vibe coding** as an experimental
> development approach to assist with refactoring and version adaptation.
>  
> Core gameplay concepts, assets, and original design remain unchanged.

A addon for [Timeless and Classics Guns Zero](https://github.com/MCModderAnchor/TACZ) that adds throwables
and extended support for gun packs.
