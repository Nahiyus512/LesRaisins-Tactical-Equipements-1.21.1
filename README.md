## Unofficial lr-tactical 1.21.1 NeoForge Port 
[![Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/mod/lr-tactical-1.21.1)
[![CurseForge](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/available/curseforge_vector.svg)](https://legacy.curseforge.com/minecraft/mc-mods/lr-tactical-1-21-1)

> [!IMPORTANT]
> This is an **unofficial** version. Support is not guaranteed and things may not work as expected  
> Please do **not** report any issues of this port to the original developers

> [!WARNING]
> This mod is only a **very early/basic port**, and there may be lots of problems  
> It can possibly break your world or corrupt data  
> Do **not** use it in important saves, and always make backups before playing  
> All item data are incompatible and may very likely cause world or data damage

Recipes in other gun packs are broken by default  
You need to use the **gun pack upgrader mod developed by MUKSC** to upgrade those packs  
to be compatible with **1.21.1 NeoForge**. Since you managed to translate this, my mod probably already knows what this is, right?

### Note
I am **not a professional mod developer**. During the porting process I used AI.  
Because of this, there may be parts of the source code that even I can’t fully explain •ᴗ•,  
so some issues might not get answers or fixes.

Right now, the mod is only tested in a **basic NeoForge 1.21.1 environment**.  
Textures, models, and recipes seem to work fine.  
However, it has **not been tested with shaders, multiplayer, or other mods**,  
so you may run into various issues while playing. Please understand,  
and I’ll try my best to fix things later.

> ⚠️ **Migration / Port Notice**
>
> This repository is a **ported and migrated version** of  
> **LesRaisins Tactical Equipements**, adapted for **NeoForge 1.21.1**.
>
> - Original repository: https://github.com/LesRaisins-Studios/LesRaisins-Tactical-Equipements
> - Original authors: xjqsh, LeComte
> - Migration & maintenance: Nahiyus512
>
> This fork focuses on **porting the project to NeoForge 1.21.1**,
> including dependency updates, mapping changes, and compatibility fixes.
>  
> Core gameplay concepts, assets, and original design remain unchanged.

A addon for [Timeless and Classics Guns Zero](https://github.com/MCModderAnchor/TACZ) that adds throwables
and extended support for gun packs.
